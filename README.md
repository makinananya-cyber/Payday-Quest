# Payday Quest

A gamified financial literacy website for teens. Players learn money skills through short lessons and quizzes, then use them in a three-month payday simulator: get a paycheck, set a budget, handle surprise events and try to reach a savings goal without going into debt.

## Features
- **Learn:** 6 levels (Paycheck, Budgeting, Saving, Banking, Credit, Investing) with lesson cards and quizzes
- **Payday simulator:** 3 characters at easy, medium and hard difficulty, with paycheck breakdowns, budget sliders, random life events and star ratings
- **Arcade:** "Need or Want?" 30-second sprint and a Compound Interest Machine
- **Progress:** XP, levels, badges and a daily streak (saved in the browser)

It is a single static `index.html` file with no build step, hosted on GitHub Pages.
